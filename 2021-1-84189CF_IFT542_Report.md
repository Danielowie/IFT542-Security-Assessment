# TASK 2: SECURE AUTHENTICATION AND SQL INJECTION REMEDIATION

## 2.1 Existing Authentication Flow (Vulnerable Baseline)

The vulnerable baseline (`legacy/login_vulnerable.php`) exemplifies three critical flaws:

```php
// VULNERABLE: String concatenation + MD5 + verbose error + no rate limit
$sql = "SELECT * FROM users WHERE email = '$identifier' AND password = '" . md5($password) . "'";
$result = $conn->query($sql);
if ($result === false) {
    die('Query failed: ' . $conn->error . ' SQL was: ' . $sql);  // Leaks schema
}
```

**Vulnerabilities Identified:**
- **SQL Injection:** Unescaped string concatenation
- **Weak Hashing:** MD5 is fast and unsalted
- **User Enumeration:** Error messages reveal valid/invalid emails
- **No Rate Limiting:** Unlimited password guesses

## 2.2 Secure Authentication (Implemented)

### Parameterized Queries

**File:** `src/Database.php`

```php
public static function run(string $sql, array $params = []): PDOStatement
{
    $stmt = self::connection()->prepare($sql);
    $stmt->execute($params);
    return $stmt;
}
```

**PDO Configuration:**
```php
PDO::ATTR_EMULATE_PREPARES = false;  // Server-side prepared statements
```

All database access flows through this single method. Example usage:

```php
// In src/Auth.php
$stmt = Database::run(
    'SELECT id, password_hash FROM users WHERE email = ? OR matric_no = ? LIMIT 1',
    [$identifier, $identifier]
);
```

**Security Property:** User input is bound as data, never interpolated into SQL code.

### Argon2id Password Hashing

**File:** `src/Auth.php` (lines 76–83)

```php
public static function hashPassword(string $password): string
{
    return password_hash($password, PASSWORD_ARGON2ID, [
        'memory_cost' => 65536,  // 64 MB (GPU/ASIC resistant)
        'time_cost'   => 4,      // 4 iterations (~100ms per hash)
        'threads'     => 1,      // Conservative for shared hosting
    ]);
}
```

**Storage:** Passwords stored only as Argon2id hashes. Example (redacted):

```
password_hash: $argon2id$v=19$m=65536,t=4,p=1$c2FsdHRzYWx0c2E$OcXjM3l0m5m0YyG3s8w2N6u5s2wq0k9Xh3m2f9pQmC0
```

**Verification:** `password_verify($submitted, $hash)` performs constant-time comparison.

### Additional Authentication Controls

| Control | Implementation | Purpose |
|---------|-----------------|---------|
| **Rate Limiting** | 5 failed attempts per 15 min (IP + email) | Brute force prevention |
| **Account Lockout** | 15-minute lockout after threshold | Automatic account protection |
| **Session Regeneration** | `session_regenerate_id(true)` on login | Session fixation prevention |
| **Timing Attack Defense** | Always run `password_verify()` (even if user not found) | Prevent user enumeration via timing |
| **Generic Errors** | Same message for all failures | Prevent user enumeration via error message |
| **Secure Cookies** | HttpOnly, SameSite=Lax, Secure (prod) | XSS/CSRF/sniffing defense |
| **Password Reset Tokens** | Single-use, hashed, time-limited | Account recovery security |

# TASK 3: WEB DEFENCES, INCIDENT RESPONSE, AND ETHICS

## 3.1 XSS Protection

**Vulnerable Baseline:** `legacy/profile_vulnerable.php` stores user bio without encoding.

```php
// VULNERABLE: Stored XSS
echo "Student bio: " . $user['bio'];  // Could contain <script>alert('xss')</script>
```

**Secure Implementation:**

```php
// In templates, all output encoded
echo "Student bio: " . e($user['bio']);

// Global helper (src/SecurityHeaders.php)
function e(?string $value): string
{
    return htmlspecialchars($value ?? '', ENT_QUOTES, 'UTF-8');
}
```

**Result:** Script tags rendered as text, not executable.

**Content Security Policy:**

```
Content-Security-Policy: default-src 'self'; script-src 'self'; 
img-src 'self' data:; object-src 'none'; frame-ancestors 'none'
```

**Defense Layers:**
1. **Output Encoding:** `<` becomes `&lt;`, quotes escaped
2. **CSP:** Browser blocks inline scripts even if encoding bypassed
3. **HttpOnly Session Cookie:** XSS cannot steal session via JavaScript

**Testing:** `evidence/task3/xss-test-results.txt` (12 tests, 100% pass)

## 3.2 CSRF Protection

**Vulnerable Baseline:** `legacy/` shows forms without tokens.

**Secure Implementation:**

```php
// Generate token (first visit)
public static function token(): string
{
    if (empty($_SESSION['csrf_token'])) {
        $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
    }
    return $_SESSION['csrf_token'];
}

// Verify token (form submission)
public static function verify(?string $submitted): bool
{
    if (empty($_SESSION['csrf_token']) || $submitted === null) {
        return false;
    }
    return hash_equals($_SESSION['csrf_token'], $submitted);  // Constant-time
}

// Rotate token (after successful state-change)
public static function rotate(): void
{
    $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
}
```

**Dual Defense:**
1. **CSRF Token:** Server validates token present and valid
2. **SameSite=Lax:** Browser doesn't send session cookie on cross-site POST

**Testing:** `evidence/task3/csrf-test-results.txt` (8 tests, 100% pass)

## 3.3 SSRF Protection

**Vulnerable Baseline:** `legacy/url_preview_vulnerable.php` fetches any URL without validation.

**Secure Implementation:** `src/UrlGuard.php`

```php
public static function isAllowed(string $url, array $allowlist): array
{
    // 1. Parse and validate format
    $parts = parse_url($url);
    if (!$parts || !isset($parts['scheme'], $parts['host'])) {
        return [false, 'Malformed URL'];
    }

    // 2. Enforce HTTPS only
    if (!in_array($parts['scheme'], ['https'], true)) {
        return [false, 'Only https URLs are permitted'];
    }

    // 3. Allowlist host
    $host = strtolower($parts['host']);
    if (!in_array($host, $allowlist, true)) {
        return [false, 'Host is not on the approved allowlist'];
    }

    // 4. Resolve hostname and check resolved IP
    $ips = gethostbynamel($host);
    if ($ips === false || count($ips) === 0) {
        return [false, 'Host did not resolve'];
    }

    // 5. Reject private/loopback/metadata addresses
    foreach ($ips as $ip) {
        if (self::isDisallowedIp($ip)) {
            return [false, 'Host resolves to a disallowed internal address'];
        }
    }

    return [true, null];
}

private static function isDisallowedIp(string $ip): bool
{
    // AWS/Azure/GCP metadata
    if ($ip === '169.254.169.254') return true;
    
    // Private/loopback/reserved via filter
    $flags = FILTER_FLAG_NO_PRIV_RANGE | FILTER_FLAG_NO_RES_RANGE;
    return filter_var($ip, FILTER_VALIDATE_IP, $flags) === false;
}
```

**Defense Mechanisms:**
- **HTTPS Enforcement:** No downgrade attacks
- **Host Allowlist:** No arbitrary site access
- **DNS Rebinding Prevention:** IP checked AFTER resolution
- **Metadata Blocking:** Explicit check for `169.254.169.254`
- **No Redirect Following:** Prevents proxy chains
- **Timeout & Size Limits:** Prevents DOS

**Testing:** `evidence/task3/ssrf-test-results.txt` (16 tests, 100% pass)
